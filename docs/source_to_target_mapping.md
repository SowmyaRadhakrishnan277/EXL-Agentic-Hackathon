# Source-to-target mapping

Legacy SQL Server / SAS estate → lakehouse (bronze / silver / gold). Generated by `python -m factory.mapping_doc runs/20261113-175507` on 2026-11-13 from the discovery and design agents' output; do not edit by hand.

| Layer | Holds | Naming rule |
|---|---|---|
| bronze | Raw source extracts, as-is, typed from the legacy DDL, plus `_ingested_at`, `_source_file` | `dbo.<t>` → `bronze.<t>` |
| silver | Cleaned, conformed and intermediate tables (legacy staging) | `stg.<t>`, SAS `stg_<t>` / `<t>` → `silver.<t>` |
| gold | Report-ready tables used by Finance, Actuarial, Reserving, Credit control | `rpt.<t>`, SAS `rpt_<t>` → `gold.<t>` |

On Databricks each table is a Delta table `workspace.<layer>.<t>` in Unity Catalog; locally a parquet folder `lakehouse/<layer>/<t>/`.
